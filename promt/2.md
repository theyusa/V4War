## ROL
Sen Jetpack Compose ve performans optimizasyonu uzmanısın.

## BAĞLAM
V4War projesinde `ProfileListScreen.kt` dosyasında aşağıdaki yapı var:
```kotlin
@Composable
fun ProfileList(profiles: List<Profile>, onEdit: (Profile) -> Unit) {
    LazyColumn {
        items(profiles) { profile ->
            ProfileCard(profile) // ❌ Tüm profile değişince rerender
        }
    }
}

@Composable
fun ProfileCard(profile: Profile) {
    Text(profile.name)
    Text(profile.server)
    Switch(checked = profile.active, onCheckedChange = { ... })
}
```

## GÖREV
1. `Profile` data class'ını `@Stable` yap veya primitive parametrelere ayır
2. `ProfileCard`'ı `key` parametresi ile optimize et
3. `derivedStateOf` ile gereksiz state hesaplamalarını önle
4. `modifier` parametresini tüm component'lere ekle

## KISITLAR
- ✅ `remember`, `derivedStateOf`, `key` doğru kullanılsın
- ✅ `Modifier` her zaman en dışta uygulanmış olsun
- ✅ `profiles` listesi `Flow<List<Profile>>` olarak gelsin ViewModel'den
- ❌ `mutableStateOf` ile profile içini mutate etme

## BEKLENEN ÇIKTI
```kotlin
// 1. Stable data class
@Stable
data class ProfileUi(
    val id: String,
    val name: String,
    val server: String,
    val isActive: Boolean,
    val lastUsed: Long
)

// 2. Optimize edilmiş composable
@Composable
fun ProfileCard(
    profileId: String,
    name: String,
    server: String,
    isActive: Boolean,
    onToggle: (Boolean) -> Unit,
    onEdit: () -> Unit,
    modifier: Modifier = Modifier
) { ... }

// 3. ViewModel'de state transformation
val uiProfiles: StateFlow<List<ProfileUi>> = profilesFlow
    .map { profiles -> profiles.map { it.toUiModel() } }
    .stateIn(viewModelScope, SharingStarted.WhileSubscribed(5000), emptyList())
```
