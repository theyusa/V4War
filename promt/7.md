## ROL
Sen DevSecOps ve GitHub Actions uzmanısın.

## BAĞLAM
V4War projesi için mevcut CI/CD:
- `android-manual-build.yml`: Manual trigger ile APK build
- `android-latest-singbox-build.yml`: Haftalık sing-box update build
- Eksik: Security scanning, dependency graph, SBOM generation

## GÖREV
1. `security-scan` job'ı ekle: Trivy + govulncheck + CodeQL
2. `dependency-submission` ile GitHub Dependency Graph entegrasyonu
3. Release pipeline'ına `gitleaks` ile secret scanning ekle
4. Build cache optimizasyonu ile CI süresini düşür

## KISITLAR
- ✅ Job'lar `needs: [build]` ile doğru sıralansın
- ✅ Secrets sadece gerekli job'larda kullanılsın (`env` seviyesinde)
- ✅ SARIF output'ları GitHub Security tab'a upload edilsin
- ✅ Cache key'leri `hashFiles('**/*.gradle*', '**/go.mod')` ile olsun
- ❌ Sensitive data log'a yazdırılmasın (`set +x` veya `mask`)

## BEKLENEN ÇIKTI: `.github/workflows/security-scan.yml`
```yaml
name: Security & Dependency Scan

on:
  push:
    branches: [ main ]
    paths:
      - 'build.gradle.kts'
      - 'libs.versions.toml'
      - 'libcore/go.mod'
      - 'libcore/**'
  pull_request:
    branches: [ main ]
    paths:
      - '**/*.kt'
      - '**/*.go'
      - '**/build.gradle*'
  schedule:
    - cron: '0 6 * * 1'  # Weekly scan

permissions:
  contents: read
  security-events: write  # For SARIF upload
  actions: read

jobs:
  dependency-graph:    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
        with:
          submodules: recursive
          
      - name: Set up JDK 21
        uses: actions/setup-java@v4
        with:
          distribution: temurin
          java-version: '21'
          
      - name: Generate and Submit Dependency Graph
        uses: gradle/actions/dependency-submission@v4
        with:
          build-root-directory: .
          dependency-graph: generate-and-submit

  trivy-scan:
    runs-on: ubuntu-latest
    needs: dependency-graph
    steps:
      - uses: actions/checkout@v4
        with:
          fetch-depth: 0
          
      - name: Run Trivy vulnerability scanner
        uses: aquasecurity/trivy-action@master
        with:
          scan-type: 'fs'
          scan-ref: '.'
          format: 'sarif'
          output: 'trivy-results.sarif'
          severity: 'CRITICAL,HIGH'
          ignore-unfixed: true
          
      - name: Upload to GitHub Security
        uses: github/codeql-action/upload-sarif@v3
        if: always()
        with:
          sarif_file: 'trivy-results.sarif'

  go-vulncheck:
    runs-on: ubuntu-latest
    needs: dependency-graph
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-go@v5
        with:
          go-version: '1.22'          cache-dependency-path: 'libcore/go.sum'
          
      - name: Install govulncheck
        run: go install golang.org/x/vuln/cmd/govulncheck@latest
        
      - name: Scan Go dependencies
        working-directory: libcore
        run: govulncheck -format json ./... > vuln-report.json
        
      - name: Upload Go vulnerability report
        uses: actions/upload-artifact@v4
        with:
          name: go-vuln-report
          path: libcore/vuln-report.json
          retention-days: 30

  secret-scan:
    runs-on: ubuntu-latest
    if: github.event_name == 'pull_request'
    steps:
      - uses: actions/checkout@v4
        with:
          fetch-depth: 0
          
      - name: Run gitleaks
        uses: gitleaks/gitleaks-action@v2
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
          GITLEAKS_LICENSE: ${{ secrets.GITLEAKS_LICENSE }} # Optional for enterprise
```

## OPTIMIZASYON EKLERİ
```yaml
# build-android job'ına cache ekle:
- name: Cache Gradle packages
  uses: actions/cache@v4
  with:
    path: |
      ~/.gradle/caches
      ~/.gradle/wrapper
    key: ${{ runner.os }}-gradle-${{ hashFiles('**/*.gradle*', '**/gradle-wrapper.properties') }}
    restore-keys: |
      ${{ runner.os }}-gradle-

- name: Cache Go modules
  uses: actions/cache@v4
  with:
    path: |
      ~/.cache/go-build
      ~/go/pkg/mod    key: ${{ runner.os }}-go-${{ hashFiles('libcore/go.sum') }}
```
