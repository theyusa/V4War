## ROL
Sen kıdemli bir Kotlin Multiplatform (KMP) ve Android mimarı uzmanısın.

## BAĞLAM
V4War projesi, Android için V2Ray/sing-box tabanlı bir proxy istemcisidir. 
Proje yapısı:
- `composeApp/`: UI katmanı (Compose Multiplatform)
- `libcore/`: Go ile yazılmış native core (CGo via FFI)
- `library/`: Paylaşılan business logic ve domain katmanı

## GÖREV
`PlatformProvider` interface'ini tasarla ve aşağıdaki platform-spesifik fonksiyonları soyutla:
1. `getPlatformName(): String`
2. `isNetworkAvailable(): Boolean`
3. `getDeviceId(): String` (privacy-safe, resetlenebilir)
4. `storeSecure(key: String, value: String): Result<Unit>`

## KISITLAR
- ✅ `expect/actual` pattern kullan
- ✅ Interface, `commonMain` içinde tanımlansın
- ✅ Android implementation'ı `EncryptedDataStore` kullansın
- ✅ iOS implementation'ı `Keychain` kullansın (yorum olarak bırak)
- ✅ Tüm fonksiyonlar `suspend` veya `Flow` döndürsün (coroutine-friendly)
- ❌ Hardcoded string/ID kullanma
- ❌ Platform spesifik import'ları common katmana sızdırma

## BEKLENEN ÇIKTI FORMATI
```kotlin
// commonMain/kotlin/tr/theyusa/v4war/core/PlatformProvider.kt
expect interface PlatformProvider { ... }

// androidMain/.../PlatformProvider.android.kt
actual class AndroidPlatformProvider(...) : PlatformProvider { ... }

// Usage örneği ViewModel içinde
class ConnectionViewModel(
    private val platform: PlatformProvider,
    private val core: LibCoreInterface
) : ViewModel() { ... }
```
