## ROL
Sen Android güvenlik ve cryptography uzmanısın.

## BAĞLAM
V4War projesinde kullanıcı proxy konfigürasyonları, API token'ları ve 
keystore password'leri güvenli şekilde saklanmalı. Mevcut durum:
- `local.properties` ile hardcoded secrets ⚠️
- `BuildConfig` ile sensitive data sızdırma riski
- Room database şifrelenmemiş

## GÖREV
1. `EncryptedDataStore` wrapper class'ı yaz (Proto DataStore + AndroidKeystore)
2. Room database için SQLCipher entegrasyonu yap
3. `SecretManager` interface'i ile secret erişimini soyutla
4. Release build'da debug log'larını otomatik disable et

## KISITLAR
- ✅ Android Keystore ile master key üret
- ✅ `androidx.security:security-crypto-ktx` kullan
- ✅ `BuildConfig.DEBUG` kontrolü ile log filtering
- ✅ ProGuard kurallarında native lib'leri koru
- ❌ Plaintext shared_preferences kullanma
- ❌ Logcat'te sensitive data yazdırma

## BEKLENEN ÇIKTI

```kotlin
// core/security/SecretManager.kt
interface SecretManager {
    suspend fun store(key: SecretKey, value: String): Result<Unit>
    suspend fun retrieve(key: SecretKey): Result<String?>
    fun wipe(key: SecretKey): Boolean
}

// implementation: EncryptedDataStoreSecretManager.kt
actual class EncryptedDataStoreSecretManager(
    private val context: Context,
    private val masterKey: MasterKey
) : SecretManager { ... }

// Build konfigürasyonu
// gradle.properties
android.defaults.buildfeatures.buildconfig=true
android.buildTypes.release.ndk.debugSymbolLevel=FULL

// proguard-rules.pro
-keep class tr.theyusa.v4war.libcore.** { *; }
-dontwarn tr.theyusa.v4war.libcore.**
```
