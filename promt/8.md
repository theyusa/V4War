## ROL
Sen release engineering ve semantic versioning uzmanısın.

## BAĞLAM
V4War sürüm yönetimi:
- `gradle.properties`: `versionCode=42`, `versionName=1.3.5`
- GitHub Releases manuel oluşturuluyor
- Changelog otomatik generate edilmiyor
- APK + AAB + SBOM artifact'leri ayrı upload ediliyor

## GÖREV
1. Semantic versioning ile otomatik version bump script'i yaz
2. Conventional Commits ile changelog generation ekle
3. Release workflow'unda: sign → build → upload → create release
4. SBOM (CycloneDX) generation ve attachment ekle

## KISITLAR
- ✅ Version bump sadece `main` branch'te, tag push ile tetiklensin
- ✅ Changelog'da `feat:`, `fix:`, `security:` prefix'leri group'lansın
- ✅ Release notes'ta: checksums, minSdk, breaking changes vurgulansın
- ✅ Artifact'ler: `apk`, `aab`, `bom.json`, `signing-verification.txt`
- ❌ Release branch'ında force push olmasın

## BEKLENEN ÇIKTI: `.github/workflows/release.yml`
```yaml
name: Release Automation

on:
  push:
    tags:
      - 'v*.*.*'  # v1.3.6 gibi tag'ler

permissions:
  contents: write
  packages: write
  id-token: write  # For signing

jobs:
  prepare-release:
    runs-on: ubuntu-latest
    outputs:
      version: ${{ steps.get-version.outputs.version }}
      changelog: ${{ steps.generate-changelog.outputs.changelog }}
    steps:
      - uses: actions/checkout@v4
        with:
          fetch-depth: 0
          
      - name: Get version from tag
        id: get-version        run: echo "version=${GITHUB_REF#refs/tags/v}" >> $GITHUB_OUTPUT
        
      - name: Generate changelog
        id: generate-changelog
        uses: orhun/git-cliff-action@v2
        with:
          config: cliff.toml
          args: --latest --strip header
        env:
          OUTPUT: CHANGES.md

  build-release:
    needs: prepare-release
    uses: ./.github/workflows/android-manual-build.yml
    with:
      version-name: ${{ needs.prepare-release.outputs.version }}
      build-type: release
    secrets: inherit

  publish-release:
    needs: [prepare-release, build-release]
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      
      - name: Download build artifacts
        uses: actions/download-artifact@v4
        with:
          pattern: v4war-*
          merge-multiple: true
          path: release-artifacts/
          
      - name: Generate SBOM (CycloneDX)
        uses: CycloneDX/gh-gomod-generate-sbom@v2
        with:
          args: mod -licenses -output release-artifacts/bom.json
          
      - name: Calculate checksums
        working-directory: release-artifacts
        run: sha256sum *.apk *.aab *.json > checksums.txt
        
      - name: Create GitHub Release
        uses: softprops/action-gh-release@v2
        with:
          body_path: CHANGES.md
          files: |
            release-artifacts/*.apk
            release-artifacts/*.aab
            release-artifacts/bom.json
            release-artifacts/checksums.txt          draft: false
          prerelease: false
          generate_release_notes: false
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
          
      - name: Notify release
        run: |
          # Optional: Discord/Telegram webhook notification
          curl -X POST ${{ secrets.RELEASE_WEBHOOK }} \
            -H "Content-Type: application/json" \
            -d "{\"text\":\"🚀 V4War ${{ needs.prepare-release.outputs.version }} released!\"}"
```

## `cliff.toml` (Changelog Config)
```toml
[changelog]
header = """
# Changelog\n
All notable changes to V4War will be documented in this file.\n
"""
body = """
{% if version %}\
    ## [{{ version | trim_start_matches(pat="v") }}] - {{ timestamp | date(format="%Y-%m-%d") }}
{% else %}\
    ## [Unreleased]
{% endif %}\
{% for group, commits in commits | group_by(attribute="group") %}
    ### {{ group | upper_first }}
    {% for commit in commits %}
        - {% if commit.breaking %}⚠️ {% endif %}{{ commit.message | upper_first }}\
          {% if commit.links %} ({% for link in commit.links %}[{{ link.text }}]({{ link.href }}){% endfor %}){% endif %}
    {% endfor %}
{% endfor %}\n
"""

[git]
conventional_commits = true
filter_unconventional = true
split_commits = false
commit_parsers = [
    { message = "^feat", group = "Features" },
    { message = "^fix", group = "Bug Fixes" },
    { message = "^security", group = "Security" },
    { message = "^perf", group = "Performance" },
    { message = "^refactor", group = "Refactoring" },
    { message = "^docs", group = "Documentation" },
]
protect_breaking_commits = true
filter_commits = true```
