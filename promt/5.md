## ROL
Sen Kotlin coroutines, Flow ve reactive programming uzmanısın.

## BAĞLAM
V4War'da connection state, profile listesi ve log stream'leri 
async olarak yönetiliyor. Mevcut implementasyonda:
- `viewModelScope.launch` içinde exception handling eksik
- `Flow`'lar `stateIn` olmadan direkt collect ediliyor
- Dispatchers kullanımı tutarsız (IO vs Default karışık)

## GÖREV
1. Tüm ViewModel'ler için standart `Result<Flow<T>>` pattern'ini uygula
2. `SharedFlow` vs `StateFlow` kullanım kılavuzu oluştur
3. `CoroutineExceptionHandler` ile global error handling kur
4. `Dispatchers` kullanımını domain'e göre standardize et

## KISITLAR
- ✅ Tüm business logic `IO` dispatcher'ında çalışsın
- ✅ UI update'ler `Main.immediate` ile optimize edilsin
- ✅ `flowOn`, `catch`, `onCompletion` operator'leri zincirlensin
- ✅ `SharingStarted.WhileSubscribed(5000)` ile gereksiz computation önle
- ❌ `GlobalScope` veya `CoroutineScope(Dispatchers.X)` kullanma

## BEKLENEN ÇIKTI
```kotlin
// core/coroutine/V4WarDispatchers.kt
object V4WarDispatchers {
    val IO: CoroutineDispatcher = Dispatchers.IO.limitedParallelism(4)
    val Default: CoroutineDispatcher = Dispatchers.Default
    val Main: CoroutineDispatcher = Dispatchers.Main.immediate
}

// base/BaseViewModel.kt
abstract class BaseViewModel : ViewModel() {
    protected val coroutineExceptionHandler = CoroutineExceptionHandler { _, throwable ->
        // centralized error logging
        Timber.e(throwable, "Unhandled coroutine exception")
    }
    
    protected fun <T> flowWithDefaultHandlers(
        flow: Flow<T>
    ): Flow<T> = flow
        .flowOn(V4WarDispatchers.IO)
        .catch { e -> 
            Timber.e(e)
            // emit error state if needed
        }
        .onCompletion { cause ->
            if (cause != null) Timber.d("Flow completed with: $cause")
        }
}

// Usage example
class ConnectionViewModel : BaseViewModel() {
    val connectionState: StateFlow<ConnectionState> = 
        libCore.connectionEvents
            .map { it.toUiState() }
            .flowWithDefaultHandlers()
            .stateIn(
                scope = viewModelScope,
                started = SharingStarted.WhileSubscribed(5000),
                initialValue = ConnectionState.Idle
            )
}
```
