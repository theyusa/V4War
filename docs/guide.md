# Kurulum ve Kullanım

## 1. İndirme
En güncel derlemeyi [GitHub Releases](https://github.com/theyusa/V4War/releases) sayfasından cihaz mimarinize uygun (`arm64-v8a` veya `universal`) APK olarak indirin.

## 2. Profil Ekleme
1. Uygulamayı açın ve sağ üstteki **+** simgesine dokunun.
2. Bağlantı adresini (`vless://`, `trojan://`, `hy2://` vb.) panodan içe aktarın veya abonelik (Subscription) bağlantısı ekleyin.
3. Alt kısımdaki başlatma butonuna basarak VPN/TUN bağlantısını aktif edin.
